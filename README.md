# WordMemoryCheat
A Python script that cheats the Human Benchmark word memory test by reading the words and checking if it has seen them or not and sending that to the website

## Setup
```
pip install selenium
```

## Usage
```
python WordMemory.py
```
or run it in your IDE.

Start the test in the browser, press Enter in the terminal, and watch it go.

## Disclaimer
For educational purposes only — a fun project to learn about screen automation in Python.
