# AimTrainerCheat
A Python script that cheats the Human Benchmark number memory test by reading the number from the page and typing it back automatically using Selenium.

## Setup
```
pip install selenium
```

## Usage
```
python Aimtrainer.py
```
or run it in your IDE.

Start the test in the browser, press Enter in the terminal, and watch it go.

## Disclaimer
For educational purposes only — a fun project to learn about screen automation in Python.
